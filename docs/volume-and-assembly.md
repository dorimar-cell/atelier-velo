# Объём, сборка, камера и студия

Детали — это фотографии. Рантайм восстанавливает из альфы объём, чтобы велосипед выдерживал орбиту, а не выглядел набором спрайтов.

## Выбор билдера

`createVolumeMesh({ texture, src, pose, type, role, layer })`:

| `type` | Билдер | Если не удалось |
| --- | --- | --- |
| `wheels` | `wheelMesh` — тор, обод-lathe, спицы, втулка | плоский `PlaneGeometry` |
| `cassette` | `cassetteMesh` — 11 звёзд + бочка | плоскость |
| `brakes` | `brakeMesh` (ротор + калипер) | inflate, затем плоскость |
| остальное | `inflateMesh` — две оболочки + борт | плоскость |
| `shadow` | только плоскость с альфой, без объёма | — |

Пресеты материала и толщины: `TYPE_PRESET` по типу и `ROLE_PRESET.interior` (тонкий карман рамы). `keepHoles: true` у тормозов — мелкие окна не заливаются.

## Общий пайплайн силуэта (`prepareSolid`)

1. Текстура даунсемплится до длинной стороны ≤ 320 (`PREP_MAX`).
2. Пиксель считается телом, если max-альфа блока ≥ 88.
3. Маска и усреднённый RGBA кладутся в `maskCache` по `src`.

`warmupVolume` / `preload` прогревают маски и геометрию в idle, чтобы первый клик не ждал триангуляции.

Для inflate маска ещё раз сжимается до ≤ 420 / 340 / 260 в зависимости от размера позы (`meshLimit`).

## Inflate (рама, руль, седло, групсет, держатели)

`buildInflateKit`:

1. Мелкие дырки, не касающиеся края, заливаются (`fillSmallHoles`), кроме `keepHoles`.
2. Считается signed distance: внутри — расстояние до фона, снаружи — отрицательное.
3. Поле сглаживается box-blur и max-filter.
4. Высота точки ≈ `sqrt(d * (2R − d)) * sz`, ограничена `preset.maxHalf`. Восемь проходов усреднения, край заужается почти до нуля — оболочка закрывается.
5. Строятся лицевая и тыльная сетки плюс борта по открытым рёбрам.
6. Контур сглаживается семью итерациями по соседям.
7. Цвет бортов — медиана «глубоких» пикселей (`deepColor`).

Дополнительные стержни, чтобы стыки не висели в воздухе:

| Роль | Функция | Как ищется якорь |
| --- | --- | --- |
| `handlebar` | `makeSteerer` — рулевая колонка вниз | нижняя часть левой половины маски |
| `saddle` | `makePostPeg` — подседельный штырь | нижняя полоса маски |
| `seat`, `down` | `makeMountPeg` — бобышка в раму | центроид маски, цилиндр вдоль −Z |

`partAnchor` и `frameSockets` умеют находить голову и седловую трубу рамы; в текущем `assemble.js` они не вызываются — стыковка идёт через общие bbox и `JOIN`.

## Колесо

`buildWheelKit`:

1. `fitCircle` по маске — центр и радиус (квантиль 0.995 / 0.997 внешних точек).
2. `radialStats` + `detectWheelBands` режут покрышку, обод, втулку; ловят tanwall по красному каналу.
3. Покрышка — `TorusGeometry`, цвет по радиусу и фото.
4. Обод — `LatheGeometry` профиля полки.
5. Лица обода и кольцо спиц — `RingGeometry` с UV из фото (`photoSkin`).
6. Втулка — отдельная механика `buildAxleGeometry`: корпус, фланцы, ось, шайбы, шестигранные колпачки. Задняя втулка длиннее и несёт freehub на приводной стороне; дисковая сторона остаётся компактной (ротор — отдельный тип `brakes`).

## Кассета

11 цилиндров убывающего радиуса на общей оси + бочка + контргайка + фото-кольцо лица. Металл — `#9a9894`.

## Тормоз

`buildBrakeKit`:

1. `fitRotorCircle` пробует полный круг и обрезанные половины — на широких спрайтах «ротор + калипер».
2. Ротор — тонкий lathe-профиль, лица с фото, шляпка центра.
3. `extractCaliperMask` оставляет связные компоненты **снаружи** радиуса ротора.
4. Калипер строится отдельным inflate с `maxHalf: 0.007`.
5. Если круга нет (только калипер) — кит не создаётся, срабатывает обычный inflate.

Тормоза садятся ближе к зрителю, чем рама (`z ≈ −0.04`), на не-приводную сторону.

## Материалы и свет

`MeshPhysicalMaterial` через `skin()`: низкий metalness у карбона, выше у стали, слабый clearcoat, `envMapIntensity` 0.14–0.32. Фото идёт как `map` + слабый `emissiveMap`, чтобы цвет не убивался студийным светом.

`applyStudioEnvironment`:

- комната 31.5×28.5×31.5, backside plaster `#e7e1d6`;
- шесть блоков-пропов;
- emissive formers (кольцо и боксы) + точечные лампы;
- четыре спота из углов и центральный point light;
- PMREM с `environmentIntensity = 0.58`;
- фон сцены `#d5cfc2`, пол — круг радиуса 6.4.

Дополнительно в `main.js` — полусферический и очень слабый key light. Тень рамы — отдельная плоскость, opacity нарастает до 0.55.

## Анимация сборки

Точки вылета `FROM` по роли (если клик не дал hint):

| Роль | Откуда |
| --- | --- |
| frame / interior | слева |
| rear / cassette | слева-снизу |
| front | справа-снизу |
| handlebar / shifter | сверху-справа |
| saddle / seat | сверху |
| drivetrain | снизу |
| down | сверху-центр |

Клик по карточке даёт `projectHint`: луч камеры пересекает плоскость `bike.root`, точка переводится в локальные координаты. Слои одной опции стартуют с шагом 90 мс и небольшим разбросом по X.

Полёт «in»: 0.86 с, масштаб 0.28 → 1, лёгкий начальный крен. Полёт «out»: 0.48 с, улетает в сторону и вверх, меш диспозится. Кривая `easeAssemble` — cubic ease-in-out с небольшим overshoot после 0.82.

`instant = true` (флаг `snap` в URL) ставит слои сразу в финальную позу — для скриншотов.

После установки `root` получает idle-motion, сила которого растёт с `selected.size`.

## Камера (`view.js`)

Не OrbitControls: камера стоит на луче цель → базовая точка, длина луча × `zoom`. `yaw` и `pitch` крутят **корень велосипеда**, не камеру.

| Параметр | Диапазон |
| --- | --- |
| pitch | −0.62 … 0.70 |
| zoom | 0.46 … 1.62 |

Базовый кадр:

| | Камера | Цель |
| --- | --- | --- |
| десктоп | `(0.92, 0.40, 3.70)` | `(0.96, 0.14, 0)` |
| мобиле | `(0.06, 0.52, 4.45)` | `(0.04, 0.28, 0)` |

Ввод:

- ЛКМ / палец на холсте — орбита (`dx * 0.0054`, `dy * 0.0036`).
- Два пальца — pinch-zoom.
- Wheel — экспоненциальный зум, `passive: false`.
- Клики по `.dock`, кнопкам и полям игнорируются (`fromChrome`).
- Контекстное меню на canvas отключено.

Сглаживание: `k = 1 − exp(−12 * dt)`.

## Звук

`unlockAudio` создаёт `AudioContext` и резюмит его по pointerdown / клику опции. Без жеста браузер блокирует звук.

- `playPlace` — два треугольных blip 420 → 620 Hz.
- `playComplete` — трезвучие 523 / 659 / 784 Hz, один раз при переходе в `complete`.

## UI-оверлей

`.ui` на весь экран с `pointer-events: none`. События включены у дока и Reset. Холст — `touch-action: none`, курсор grab / grabbing.

Цвета: фон `#d5cfc2`, акцент `#7a4e24`, панели полупрозрачный кремовый. Активный чип типа — тёмный, выбранная карточка обведена ink.
