# Сборка, тень и Flame Wrap

На `feat/flame-wrap-complete` детали остаются фотографиями на плоскостях. Ветка меняет финал: готовую контактную тень не оставляют одной PNG-пластиной — над овалом стабильно горит шейдерное пламя.

Референс шейдера: [Canvas UI Flame Wrap](https://canvasui.dev/docs/components/flame-wrap?intensity=1.5), `intensity = 1.5`.

## Слои деталей

`makeMesh` строит `PlaneGeometry(pose.w, pose.h)` и `MeshBasicMaterial`:

- `map` — PNG слоя, `SRGBColorSpace`, anisotropy 8;
- `transparent: true`, `depthWrite: false`, `DoubleSide`;
- `alphaTest: 0.04` у деталей; у тени `alphaTest` снимается, чтобы мягкий овал не обрезался.

Объёма нет: с фиксированной камеры это читается как собранный силуэт. Flame Wrap не «надувает» велосипед — он живёт только в плоскости тени.

## Анимация сборки

Точки вылета `FROM` по роли (если клик не дал hint):

| Роль | Откуда |
| --- | --- |
| frame / interior | слева |
| rear / cassette | слева-снизу |
| front | справа-снизу |
| handlebar / shifter | сверху-справа |
| saddle / seat | сверху |
| drivetrain | снизу |
| down | сверху-центр |
| shadow | почти на месте, чуть снизу |

Клик по карточке даёт `projectHint`: луч камеры пересекает плоскость `bike.root`, точка переводится в локальные координаты. Слои одной опции стартуют с шагом 90 мс и небольшим разбросом по X.

Полёт «in»: 0.86 с, масштаб 0.28 → 1, лёгкий начальный крен. Полёт «out»: 0.48 с, улетает в сторону и вверх, меш диспозится. Кривая `easeAssemble` — cubic ease-in-out с небольшим overshoot после 0.82.

`instant = true` (флаг `snap` в URL) ставит слои сразу в финальную позу — для скриншотов и `test:flame`.

После установки `root` получает idle-motion, сила которого растёт с `selected.size`.

## Фото-тень

`placeShadow()` вызывается при выборе любой рамы:

1. Если группы `shadow` ещё нет — кладёт PNG-овал с `opacity = 0` и `userData.fade = 0`.
2. Если Flame Wrap ещё не создан — вызывает `createShadowFlame(worldOf(shadowLayer), texture)` и вешает группу на `root`.

Каждый кадр fade нарастает со скоростью `1.4 / с` до 1. Итоговая прозрачность:

```
opacity = fade * lerp(0.55, 0.4, flameReveal)
```

Овал не исчезает: он остаётся контактом с полом. Пламя его только приглушает. Проверка `verify-flame.mjs` требует `0.2 < shadowOpacity ≤ 0.5` на готовой сборке.

`reset` не удаляет тень полётом «out» отдельно от групп: `clearType("shadow")` уводит овал, а пламя гасится через `setActive(false)`.

## Flame Wrap

### Раскладка (`shadowFlameLayout`)

Константы: `PX_PER_WORLD = 180`, `GLOW_PX = 36`, высота пламени по умолчанию 92 px.

| Величина | Смысл |
| --- | --- |
| `planeW` | ширина тени + свечение с двух сторон |
| `planeH` | высота тени + `height * 1.45` + свечение — запас вверх под языки |
| `half` | внутренний прямоугольник огня: `0.44 * ширина тени` по X, 5 px по Y |
| `center` | центр этого прямоугольника в пикселях RT |
| `meshY` | сдвиг плоскости вниз, чтобы внутренний центр совпал с `pose.y` |
| `meshX`, `meshZ` | те же, что у фото-тени (`z = 1 * 0.0018`) |
| `radius` | скругление 5 px |

Плоскость больше фото-тени и не прыгает: `shadowFlameLayout` детерминирован, `localPose()` не меняется от кадра к кадру. Юнит-тесты это фиксируют.

### Жизненный цикл

`createShadowFlame` возвращает:

| Метод | Поведение |
| --- | --- |
| `setActive(on)` | желаемое состояние; само появление/исчезновение идёт в `tick` |
| `tick(dt, time)` | линейно гоняет `reveal` к 0 или 1, пишет uniforms, возвращает сглаженное значение |
| `getReveal()` | `easeReveal(reveal)` — smoothstep |
| `localPose()` | `{ x, y, z }` меша в локальных координатах корня |
| `dispose()` | геометрия и материал |

Скорости: `REVEAL_IN = 2.2` с, `REVEAL_OUT = 0.75` с. Кривая `easeReveal` — smoothstep `t²(3 − 2t)`.

Пока `shown ≤ 0.001`, группа и меш скрыты (`visible = false`). `frustumCulled = false`, `renderOrder = 2`, `depthWrite = false`, `toneMapped = false`.

### Что нарастает вместе с reveal

| Uniform | На старте | В финале |
| --- | --- | --- |
| `uReveal` | 0 | `easeReveal(reveal)` |
| `uIntensity` | 0 | `1.5 * shown` |
| `uHeight` | 40 | lerp → 92 по `shown²` |
| `uSparks` | 0 | `0.85 * shown²` |
| `uSmoke` | 0 | `1.1 * shown` |
| `uTime` | — | `time * 0.22` |

Остальные параметры сразу из `FLAME_DEFAULTS`: цвет `[0.31, 0.54, 1]`, spread 12, scale 0.48, turbulence 0.28 / 0.42 / 18, rim 1.8, melt 1.8, distortion 5, ember 1.35, scorch 0.55.

`uHasContent` остаётся `0`. Текстура тени передаётся в `uContent`, но ветка шейдера с выжиганием фото не включается: пламя рисуется вокруг тонкого скруглённого прямоугольника, а не по силуэту овала. Фото-тень — отдельный меш под ним.

### Шейдер

GLSL3, отдельные `VERT` / `FRAG`. Фрагмент считает SDF скруглённого прямоугольника, языки (`fbm` / `snoise`), melt по верхнему краю, искры (две сетки hash), дым, fade к краям RT. Это порт Canvas UI Flame Wrap, подогнанный под плоскость тени, а не DOM-оверлей.

## Камера

Не OrbitControls и не `view.js`. Каждый кадр:

| | Камера | Цель |
| --- | --- | --- |
| десктоп | `(0.92, 0.40, 3.70)` | `(0.96, 0.14, 0)` |
| мобиле | `(0.06, 0.52, 4.45)` | `(0.04, 0.28, 0)` |

Указатель на холсте сцену не крутит. Жесты нужны только доку и Reset.

## Студия и свет

`applyStudioEnvironment`:

- комната 31.5×28.5×31.5, backside plaster `#e7e1d6`;
- шесть блоков-пропов;
- emissive formers (кольцо и боксы) + точечные лампы;
- четыре спота из углов и центральный point light;
- PMREM с `environmentIntensity = 1.42`;
- фон сцены `#d5cfc2`, пол — круг радиуса 6.4.

В `main.js` дополнительно key / fill / rim. Тон-маппинг — ACES, exposure 1.18. Пламя не тон-мапится (`toneMapped: false`), поэтому синий огонь не уходит в серость.

## Звук

`unlockAudio` создаёт `AudioContext` и резюмит его по pointerdown / клику опции. Без жеста браузер блокирует звук.

- `playPlace` — два треугольных blip 420 → 620 Hz.
- `playComplete` — трезвучие 523 / 659 / 784 Hz, один раз при переходе в `complete` (по `selected.size`, не по окончанию полётов). Пламя в этот момент ещё может нарастать.

## UI-оверлей

`.ui` на весь экран с `pointer-events: none`. События включены у дока и Reset.

Цвета: фон `#d5cfc2`, акцент `#7a4e24`, панели полупрозрачный кремовый. Активный чип типа — тёмный, выбранная карточка обведена ink.

Класса `.flame-layer` в разметке нет. `debugState().hasDomOverlay` должен быть `false`.
