# Отладка и проверка

## URL-параметры

Разбор в конце `src/main.js`.

| Параметр | Пример | Поведение |
| --- | --- | --- |
| `pick` | `?pick=artik-white,scope-artech,manto-bar` | последовательно вызывает `bike.select(option)` для каждого id |
| `snap` | `&snap` | ставит детали мгновенно, без полёта |

Неизвестный id молча пропускается. После пресета UI и активный тип синхронизируются: активным становится тип **следующий после последней успешно выбранной** опции.

Полная белая сборка:

```
http://127.0.0.1:5173/?pick=artik-white,scope-artech,manto-bar,nack-seat,sram-red,cass-xplr,brake-force,bottles-two&snap
```

Тёмная:

```
http://127.0.0.1:5173/?pick=gris-veleta,zipp-303,manto-bar,nack-seat,sram-red,cass-red,brake-xplr,bottles-two&snap
```

Astur / RED:

```
http://127.0.0.1:5173/?pick=astur,scope-r4g,manto-bar,nack-seat,sram-red,cass-red,brake-red,bottles-one&snap
```

## `window.__atelier`

Доступно в консоли после загрузки модуля.

### `debugState()`

Обходит `bike.root` и возвращает:

```ts
{
  complete: boolean,          // selected.size >= 8
  selected: string[],         // id опций в порядке обхода Map
  volumes: number,            // узлы с userData.volume
  meshes: number,             // THREE.Mesh
  poses: {                    // слои с pose
    role: string,
    x: number, y: number, z: number
  }[]
}
```

Координаты поз округляются до 4 знаков.

### `setView(yaw, pitch, zoom)`

Ставит желаемые и текущие углы сразу, без сглаживания. Pitch и zoom клампятся теми же лимитами, что и жест. Нужен скриптам скриншотов, чтобы кадр был детерминированным.

## Юнит-проверки меша

`.shots/test-mesh.mjs` импортирует `solid.__test` и гоняет синтетические маски (нужен окружение с Three.js / Vite-резолвом аддонов). Покрывает:

- заливка мелких дыр и сохранение больших окон;
- inflate: две оболочки, кромка схлопывается, светлый цвет спинки;
- втулка: длинная ось, задняя длиннее передней, дисковая сторона без «блина»;
- колесо: обод не красится в tanwall, есть шина / обод / втулка;
- кассета — стопка, не конус;
- тормоз — тонкое кольцо; широкий спрайт находит ротор и отделяет калипер; вертикальный «только калипер» не выдумывает диск; вентилируемый ротор остаётся компактным кругом.

Хелперы в `__test`: `fillSmallHoles`, `buildInflateKit`, `buildWheelKit`, `buildCassetteKit`, `buildAxleGeometry`, `buildBrakeKit`, `fitRotorCircle`, `extractCaliperMask`, `presetOf`, `bandAverage`, `detectWheelBands`, `averageOpaqueColor`.

## Визуальные скрипты (Playwright)

Каталог `.shots/` в `.gitignore`. Скрипты ждут `http://127.0.0.1:5173` (часть файлов захардкодила 5175/5176 — поправьте URL или поднимите `VELO_URL`).

Playwright **не** прописан в `package.json`; для запуска нужна локальная установка `playwright` / `chromium`.

| Скрипт | Что делает |
| --- | --- |
| `verify-volume.mjs` | полный snap-пресет, фронт / орбита / крутой ракурс |
| `verify-solid.mjs` | белый и тёмный пресеты, серия ракурсов, проверка `complete` и числа мешей ≥ 20 |
| `verify-fit.mjs` | тёмный / белый / красный пресеты, стыки и хабы |
| `verify-focus.mjs` | клипы кабины, седла, втулок, труб |
| `verify-close.mjs` | крупные планы передней и задней втулки |
| `verify-flame.mjs` | **устарел**: ждёт `hasDomOverlay` / `flameReveal`, которых больше нет в `debugState` |

Типичный прогон:

```bash
npm run dev
# в другом терминале, из корня репозитория:
node .shots/verify-solid.mjs
```

Скриншоты пишутся в `.shots/*.png`.

## Ручная проверка после изменений

1. Пустая сцена: только пол и студийный фон, док с одним активным типом «Рама».
2. Выбор рамы: два слоя + появление тени.
3. Колёса: два прилёта, втулка читается с дисковой и приводной стороны.
4. Руль и седло сидят на плоскости рамы, стержни входят в трубы.
5. Групсет: шатуны снизу, манетка на руле.
6. Кассета на задней втулке, не пересекает ротор.
7. Тормоза: тонкие диски, калипер снаружи ротора, диски на не-приводной стороне.
8. Замена любой детали — старая улетает, новая садится в ту же позу.
9. Reset возвращает шаг `00 / 08` и камеру.
10. Орбита + зум не ломают материалы (нет чёрных дыр в трубах, обод не залит tanwall).
11. Мобильная ширина < 860: велосипед по центру, опции скроллятся горизонтально.

## Известные ограничения

- Нет серверной валидации совместимости группсета / кассеты / роторов.
- `process_parts.py` с абсолютным Windows-путём.
- Старый flame-оверлей удалён из рантайма, но `verify-flame.mjs` ещё ссылается на него.
- Геометрия кэшируется до перезагрузки вкладки: смена каталога на лету не сбрасывает `geomCache`.
- `disposePartMesh` чистит геометрию инстанса; общие киты в `geomCache` живут дальше (клоны).
